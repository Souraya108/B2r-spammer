1. Project Overview

B2R Safe Channel Messenger is a lightweight messaging automation utility designed to support controlled message delivery, workflow testing, and educational experimentation.

Developed under the B2R Server community, the project aims to provide a configurable messaging environment with an emphasis on reliability, operational control, and responsible usage.

Its design prioritizes simplicity, configurable execution parameters, and safeguards against excessive or unintended message delivery.

2. Core Capabilities

- Automated Message Delivery — Facilitates predefined message delivery in authorized channels.
- Custom Message Configuration — Supports configurable message content.
- Execution Intervals — Provides control over the timing of message delivery.
- Channel Configuration — Allows users to specify authorized testing channels.
- Rate Limiting — Helps prevent excessive messaging activity.
- Duplicate Prevention — Minimizes unnecessary repeated messages.
- Execution Control — Provides an option to terminate an active process.
- Safety Mechanisms — Encourages controlled and responsible operation.

3. Intended Use
